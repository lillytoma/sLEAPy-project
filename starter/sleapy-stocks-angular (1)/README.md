# sLEAPy Stocks — Angular export

Standalone Angular 17 version of the sLEAPy Stocks application.

## Requirements

- Node.js 20+
- pnpm

## Run locally

```bash
pnpm install
pnpm start
```

Open `http://localhost:4200`.

## Production build

```bash
pnpm build
```

The production output is written to `dist/sleapy-stocks`.
